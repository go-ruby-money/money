# Ruby examples

Pure-Ruby examples for the `money` library as provided by
[go-embedded-ruby](https://github.com/go-embedded-ruby/ruby) (rbgo). Run them
with the `rbgo` interpreter:

```sh
rbgo examples/money_usage.rb
```

| File | Shows |
| --- | --- |
| [`money_usage.rb`](money_usage.rb) | `Money.new`, `format`, `to_s` and arithmetic. |

Each example is executed as-is under rbgo (`require "money"`).
